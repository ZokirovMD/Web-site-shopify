**Статус: предпроектная подготовка, версия 2.0. Кода ещё нет — намеренно.**

## Два механизма

**Проекция считает будущее вперёд.** Объявил правило один раз — все модули читают
из одной проекции. Цели сами знают дату закрытия.

**Клод внутри системы, а не рядом.** Ставишь цель в ORBIT — план тренировок и питания
появляется в ORBIT, а не в чате.

## Инструменты проекта

- **[Impeccable](https://github.com/pbakaus/impeccable)** — дизайн-язык, по которому
  выбрано и зафиксировано направление
- **Pika Plugins** — 20 скиллов для бренд-контента и видео
- **Neon MCP**, **Vercel MCP** — подключены, база и деплои управляются из чата
- **pika-mcp** — добавлен в конфиг, ожидает OAuth-авторизации (`/mcp` в интерактивной сессии)

Восстановить скиллы после клонирования: `npx skills install`
